# Contributing to MIT CS Study Notes

Thank you for your interest in contributing! This document provides guidelines for contributing to this project.

## Code Style

- Follow PEP 8 style guide for Python code
- Use clear, descriptive variable names
- Add comprehensive comments explaining complex logic
- Include docstrings at the beginning of each file or function

## Comments and Documentation

- Write clear, grammatically correct comments
- Explain the "why" behind the code, not just the "what"
- Use proper formatting and punctuation in comments
- Include examples when helpful

## Adding New Content

1. Create a new file or folder following the existing structure
2. Add comprehensive comments to all code
3. Include a descriptive heading at the top of the file
4. Update relevant README or index files

## Submitting Changes

1. Make your improvements or additions
2. Test your code thoroughly
3. Ensure all comments are clear and well-written
4. Submit a pull request with a clear description of changes

## Quality Standards

- All Python files must have header comments/docstrings
- Comments should be grammatically correct
- Code should follow consistent naming conventions
- Complex algorithms should be well-documented

## Questions?

If you have questions or suggestions, please open an issue or contact the maintainers.
