# MIT CS Study Notes

A comprehensive collection of study materials, assignments, and lecture notes from MIT's Computer Science curriculum.

## Contents

- **Lectures/**: Lecture materials and code examples from each class session
- **Assignments/**: Programming assignments and problem sets with solutions
- **Exams & Solutions/**: Quiz and exam materials with detailed solutions
- **assets/**: Supporting images and resources

## Structure

```
MIT-CS-Study-Notes/
├── Lectures/        # Class lectures with code demonstrations
├── Assignments/     # Problem sets and coding assignments
├── Exams & Solutions/ # Quizzes and exams
└── assets/          # Images and supporting files
```

## Getting Started

1. Navigate to the specific lecture or assignment folder
2. Review the code examples and explanations
3. Try running the Python scripts to see the output
4. Complete practice problems in the Assignments folder
